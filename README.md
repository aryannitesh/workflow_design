# Workflow Design

Custom Frappe app that extends standard ERPNext procurement doctypes with configurable workflows,
custom fields, notifications, scheduler jobs, reports, and portal customizations.

## Covered Doctypes

- Material Request
- Request for Quotation
- Supplier Quotation
- Quotation
- Purchase Order

## Installation

```bash
bench get-app workflow_design
bench --site your-site install-app workflow_design
```
